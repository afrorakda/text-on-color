# #88 Text on Color

A high-speed contrast visualizer for UI designers. Stop guessing whether to use white or black text; let the tool decide based on WCAG standards.

## 1 Tool / 1 Action
- **Input:** Type a 6-digit HEX code or pick a color.
- **Action:** The entire screen transforms into your chosen background color, instantly identifying the most readable text color.
- **Output:** Tap a color card to copy the best-performing HEX code.

## Features
- **Dynamic Immersion:** The tool's background changes in real-time, providing an immediate "feel" for the UI's atmosphere.
- **Half & Half Cards:** Visual candidate cards split between background and text colors to ensure visibility even on white/black themes.
- **Smart Context UI:** The input card automatically adjusts its transparency and shadows based on the background's luminance to stay legible without being distracting.
- **QWERTY Optimized:** Specifically configured to trigger the alphanumeric keyboard on iOS/Android for seamless HEX entry.
- **One-Tap Reset:** Quick clear button to start fresh instantly.

## Design System
- **Background:** Dynamic (User-defined)
- **Border Radius:** 15px
- **Contrast Logic:** WCAG 2.1 Luminance-based scoring.
